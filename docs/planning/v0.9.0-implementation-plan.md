# v0.9.0 implementation and acceptance map

Approved scope: v0.8.0 / `8d6c54f` → U05, U01 incremental identity, U10 open reports.
Registry publication and SDK product rollout are separate actions.

| Phase | Implementation | Acceptance |
| --- | --- | --- |
| P0 contract | `continuous/model.rs`, `control.rs`, independent handle, private builder options, typed snapshots and additive capability query | Native/WASM examples, legacy compatibility matrix |
| P1 identity | `playlist/reconcile.rs`, generation/epoch/sequence slots, KEY/MAP overlap, atomic queue, bounded dedup history | rolling/EVENT/rewrite/restart/large integer tests |
| P2 incremental media | `continuous/engine.rs`, resource/raw sample crypto reuse, bounded probe/lookahead, shared time mapping, gaps/ranges/split | clear/sample/AES independent decode, dual EOF, epoch/range tests |
| P3 lifecycle | caller-polled runner, cancel signal, host waiter, VOD pause acknowledgement, stop drain and bounded queues | pending key/writer/acquisition/final flush, reentrant waiter, Drop and runtime Promise failures |
| P4 output/report | `continuous/output.rs`, fMP4 writer, bounded collector, native no-clobber publication, ordered events and bounded report history | Native/FFmpeg, split, sink-close failure, fixed-budget scaling |

Release status and actual evidence are recorded in [release-0.9.0.md](../release-0.9.0.md)
and its machine evidence. Public integration instructions are in
[continuous-sessions.md](../continuous-sessions.md).

Deferred as approved: multi-audio/subtitles/Packed AAC to v0.10; persistent
multi-input checkpoint, GCM and hls-engine rename to v1.0. No second descriptor
write API. The SDK retains polling, retry and initial-position policy.
